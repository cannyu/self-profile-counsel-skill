# 高性价比人生指南组合规则

仅在 `/me` 用户问题需要具体行动、取舍或代价判断时使用本文件。指南负责通用证据与排序方法，画像负责个人事实与约束；不要把指南正文复制进画像。

## 获取指南

**REQUIRED SUB-SKILL:** Use `life-decision-guide`.

先读取该技能完整的 `SKILL.md`，再按其中的本地或远程流程获取正文。若当前环境没有自动加载该技能，按以下顺序查找：

1. 用户本次明确指定的指南目录。
2. 环境变量 `LIFE_DECISION_GUIDE_ROOT`。
3. `${CODEX_HOME:-$HOME/.codex}/skills/life-decision-guide`。

不得把画像内容发送给远端仓库、搜索服务或其他外部服务。指南不可用或命中内容无法核对时，如实标「未查指南」，并且不补写书中数字、法条、DOI 或结论。

## 两套证据

| 来源 | 可以回答 | 不可回答 |
| --- | --- | --- |
| 人物画像与 evidence ledger | 个人事实、目标、时间窗、资源、不可牺牲项 | 书中通用效果、证据等级、法条与政策 |
| 《高性价比人生指南》正文 | 通用动作、成本标签、收益、证据等级、出处 | 用户是否拥有某项资源或是否愿意接受某种代价 |

画像事实决定“这个方案对本人是否成立”；指南决定“这个方案通常花什么、换什么、证据多强”。书中的默认价值排序不能覆盖画像中已确认的不可牺牲项。

## 执行顺序

1. **先做安全判断。** 急症、自杀风险或正在进行的法律程序按指南第 0 步立即分流，不先做性价比排序。
2. **读画像。** 读取 `profile.index.json` 和与问题相关的事实模块、来源文档；只提取决定本问题所需的时间窗、金额、精力、风险、受益人和不可牺牲项。
3. **读指南。** 按指南定位 1 到 3 节，完整读取命中的 1 到 3 条，包括备注、争议、例外、日期和来源。答复保留章节与条目标题，方便回查；不要只读标题。
4. **建立候选方案。** 每个候选写明动作、成本、收益、证据等级、指南出处，以及它依赖的个人事实或前提。
5. **过滤。** 删除违反已确认约束、依赖不存在资源、适用人群不符或证据为 `TODO` 的条目，并说明不采用的原因。
6. **排序。** 使用指南自己的性价比档和证据排序；不同收益口径分别排序。画像只用于判断适配度与可行性，不自行重算书中数字。
7. **合成答复。** `/me` 控制篇幅、语气和个性化；指南控制证据与出处。默认只保留前 3 个适配动作，用户要求展开时再列完整候选。

## 冲突与写回

- 指南建议与画像事实冲突：先按事实修正适用条件，再说明冲突；不得为了采用指南而修改事实。
- 指南建议与不可牺牲项冲突：列为“不采用/需先改前提”，不要把指南排序包装成用户价值。
- 同一本书条目在不同人口、病情、地区或政策下适用范围不同：保留限制；不确定时标待确认。
- 新决定、偏好或行动只有来自用户明确表态时才写回画像。指南建议本身不得写回事实层；关联时使用用户表态作为 source，并保留指南引用作为依据。
- 用户只是询问、并未接受建议时，不改写目标、价值或行动状态。

## 答复格式

先给一句结论，然后最多三个要点。每个要点压缩成：

`动作 → 花什么 → 换什么 → 证据等级 → 指南“第 N 节第 M 条（标题）” → 对本人的适用条件`

最后只给一个最小可执行动作或一个反问。找不到个人事实或缺指南证据时，直接写明缺什么；不把常识、推测或书的默认排序冒充已确认的个人结论。
